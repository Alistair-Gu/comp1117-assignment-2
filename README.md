## Getting the starting files

The starting files are in the [A2 repository on GitHub](https://github.com/Alandougherty/comp1117_assignment_2_2026AB). It is a template repository, so you make your own copy of it. Use one of these two ways.

**Way 1: your own private copy on GitHub.**

1. Open the A2 repository page.
2. Choose **Use this template**, then **Create a new repository**.
3. Give it a name, and set it to **Private**.
4. Choose **Create repository**, then clone your new repository to your computer.

**Way 2: no copy on GitHub.** Clone the A2 repository straight to your computer, without forking it.

Do not fork the repository, and do not make your copy public. A fork or a public repository shares your work with others, and that counts as sharing under [Academic integrity](AI-use.md#academic-integrity).


Keep your assignment files together in one folder.
